# Agents Kit

My personal collection of skills, agents, and workflows for Claude Code and Codex, shaped around my preferences and habits.

## Features

- **Planning and tasks:** refine ideas, plan work, and keep context and results across sessions.
- **Implementation and agents:** execute plans and handle smaller changes.
- **[Reviews](./skills/review-code/SKILL.md) and Git:** review code and docs, verify findings, and manage commits and rebases.
- **Writing:** tickets, status updates, diagrams, proofreading, dictation, and translation.
- **Knowledge upkeep:** review notes and revisit topics.
- **[Secretary](./skills/start-secretary/SKILL.md):** maintain a private runbook and sync meeting notes.
- **[Shared rules](./CORE_RULES.md):** conventions for engineering, documentation, and task work.
