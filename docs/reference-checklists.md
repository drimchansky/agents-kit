# Reference checklists

The kit ships domain checklists in `references/engineering/` that engineering skills (especially `implement-plan` and `review-code`) consult when relevant. Run `ls references/engineering/` to see the current set.

`review.md` is the shared lens & calibration source for `/review-code` — extracted from `SKILL.md` so the skill body stays mode-specific while the lens content lives in one place.

Other domains (e.g. prose, design) can live as siblings under `references/` as new subdirectories appear; the standalone utilities (`proofread`, `translate`, `fact-check`) deliberately omit a References block today.
